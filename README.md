# Projetos de Cálculo Numérico - UnB 2026-2
## Universidade de Brasília, Departamento de Engenharia Mecânica, ENM0227 - Cálculo Numérico, Semestre: 2026-2, João Bruno de Araújo
### Resumo:
Programas e códigos produzidos durante a diciplina de Cálculo Numérico para a solução de problemas apresentados durante o semestre. O objetivo é guardar todo o trabalho feito de forma organizada para que possa ser utilizado futuramente em outros projetos ou para estudo posterior.
Todos os problemas, apesar de possuírem natureza mecânica, tem como objetivo demonstrar o uso de diferentes métodos numéricos para diversos problemas, sendo central o método e não o objetivo de aplicação.

## Topologia do Repositório:
Todos os trabalhos serão nomeados de acordo com a natureza da tarefa requisitada:

* PPC_i (Programa Para Casa): Códigos motivados por tarefas avaliativas;
* EXT_i (Extras): Códigos escritos para tarefas extras que não serão avaliadas, entretanto servem como estudo.

Todos os trabalhos serão numerados de acordo com a ordem que foram realizados.
